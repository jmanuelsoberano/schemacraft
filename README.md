# SchemaCraft

Next-gen desktop CASE tool for database reverse engineering, ERD modeling, and schema visualization.

## Overview
SchemaCraft connects to relational databases, extracts metadata, persists schemas locally to prevent redundant queries, and provides dynamic, high-performance ERD visualizations with clean single-file vector/interactive exports.

See detailed specifications in the project documentation: `02_Docs/PRD_SchemaCraft_v1.md`.
